## Requesting a Commercial License

Submitting an inquiry via the Wazir Portal (`https://wazir.wael.bot/licensing`) or GitHub Issues/Discussions **does not** automatically grant a commercial license. Each request is reviewed individually.

To request commercial authorization, provide:
1. Organization name and primary contact
2. Intended deployment scope (internal enterprise fleet, OEM, managed service)
3. Estimated number of nodes/users
4. Required support or indemnification terms

Contact: `https://github.com/whassan007/wazir` or via the Commercial License Request form on `https://wazir.wael.bot`.
