Input protocol:
- `.smt2` files or `metadata.smtLib` contain declarations; assertions/check commands in these files are rejected to prevent contaminating the independent vacuity probes. `assumptions` and `guarantee` contain SMT expressions. Optional `metadata.precondition` is an SMT expression; `metadata.implementation` is an expression or expression array. Adapter builds A and A + precondition probes, followed by A + precondition + implementation + NOT guarantee.
- `.py` scripts execute from the exact hashed source, using the pinned Python, and emit JSON or `STATUS: ...`. JSON supports `status`, `solver_result`, `witness`/`model`, `vacuityProbe`, and `scope`. Optional metadata.args supplies script arguments. Exit 2 supports the stopping-rule example's counterexample convention; other runtime failures remain ERROR.
- Python pass claims require explicit same-run vacuityProbe.passed evidence; legacy stopping-rule scripts without probe evidence yield UNKNOWN for pass claims. Python scripts are trusted reviewed encodings: the adapter cannot independently establish that arbitrary Python checked the intended formula.
- SHA-256 binds obligation, artifact content and workspace revision; results record actual version, seed, elapsed time, stdout/stderr and scope.

Resource isolation:
- Temporary working directory, isolated Python mode, deterministic Z3 seeds, process-group kill on timeout and output cap.
- Z3 memory cap plus RSS watchdog; Linux also uses RLIMIT_AS. macOS rejects RLIMIT_AS, so RSS watchdog supplies process memory enforcement there.
- macOS sandbox-exec denies network and file writes outside the temporary directory. Linux has resource isolation but no equivalent filesystem/network sandbox in this implementation; deployment requires an external sandbox on Linux.

Known limits / unexecuted:
- Arbitrary standalone SMT command transcripts are deliberately unsupported; use the separated encoding protocol above.
- Native z3 CLI backend is not implemented; SMT-LIB is executed through real Z3Py in the pinned venv.
- Full repository suite and cross-platform execution were not run. No simulator/demo integration was in this agent's owned scope.
