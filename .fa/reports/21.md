## API (`packages/assurance/src/probes.ts`)

Each probe returns a `VacuityProbeResult`. When it fails, `reason` is set, and `details` echoes the inputs. Every probe fails closed: NaN, negative, fractional or inconsistent counters never pass.

| Function | Passes when |
|---|---|
| `checkZ3VacuityProbe({assumptionsSat, preconditionSat, details?})` | both are `true`; caller `details` are merged in |
| `checkAlloyVacuityProbe({runWitnessCount, runSat, commandLabel?})` | `runSat` and `runWitnessCount ≥ 1` (an integer) |
| `checkDafnyVacuityProbe({requiresSatisfiable, smokeTested, canCallersSatisfy})` | all three are `true` |
| `checkScenicVacuityProbe({attempted, generated, rejected, maxRejectionRate?})` | `attempted > 0`, `generated > 0`, `generated + rejected ≤ attempted`, and `rejected/attempted ≤ maxRejectionRate` (default `DEFAULT_SCENIC_MAX_REJECTION_RATE = 0.95`; it must be in [0,1]). `details.rejectionRate` is recorded. |
| `checkVerifaiVacuityProbe({samplesEvaluated, monitorEvaluated})` | `monitorEvaluated` and `samplesEvaluated ≥ 1` |
| `checkGamVacuityProbe({rulesCount, ontologyGrounded})` | `rulesCount ≥ 1` and `ontologyGrounded` |
| `enforceVacuityProbeOnResult(result, probe?)` | see below |

`checkVerifaiVacuityProbe` was not in the task's function list, but the commit title names VerifAI, so I added a minimal one. VerifAI never yields PROVED or BOUNDED_PASS, so this probe only records that a NOT_FALSIFIED result was not vacuous.

### `enforceVacuityProbeOnResult`

- It delegates to `applyVacuityProbe` from `verdict.ts`, so there is a single rule: PROVED or BOUNDED_PASS without `probe.passed === true` becomes `INCONSISTENT_ASSUMPTIONS`. All other verdicts pass through unchanged.
- **Design choice:** when `probe` is omitted, it uses `result.vacuityProbe`, so adapters that already attach their probe can call `enforceVacuityProbeOnResult(result)`. An explicit `probe` overrides the attached one. The probe used is written back to `vacuityProbe`.
- On a downgrade it adds `metadata.vacuityDowngrade = { from, reason }`. The reason is `'vacuity probe missing'` or the probe's own reason. Other metadata is kept.
- It returns a new object and does not mutate its input (a test checks this).
