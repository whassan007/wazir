## What was done

1. **Extraction.** Ran the §1 `extract_skills.py` from `docs/formal-assurance/SKILLS_INSTALL.md`, copied verbatim into a scratch dir outside the repo and run with `python3 -I`, into a scratch target. It wrote 28 files, and all 28 SHA-256 prefixes match the bundle's file inventory. The inventory's "Bytes" column disagrees for files with non-ASCII text (for example `gam/SKILL.md` is 14,292 bytes on disk against 14,103 listed). It appears to count characters, and the hashes match, so I treated the content as verbatim.
2. **Placement** (real files):
   - `skills/formal/alloy/` ← `alloy-formal-modeling/`
   - `skills/formal/{z3,dafny,scenic,verifai}/` ← `wazir-formal-assurance-skills/skills/<s>/`
   - `skills/formal/gam/` ← `gam/`
   - `skills/formal/evidence.schema.json` ← the bundle schema, unchanged. Build on this one; there is no competing schema.
   - `skills/formal/scripts/validate_skills.py` ← bundle validator, made layout-agnostic (see below)
   - `skills/formal/README.md`: a new README covering layout, rewrites, the re-sync recipe and checks
3. **Compatibility layouts** (relative symlinks, so both upstream conventions resolve to the same files):
   - `skills/formal/alloy-formal-modeling -> alloy`
   - `skills/formal/wazir-formal-assurance-skills/skills/{z3,dafny,scenic,verifai} -> ../../<s>`
   - `skills/formal/wazir-formal-assurance-skills/{evidence.schema.json,scripts/validate_skills.py}` link to the real files
   - `skills/formal/wazir-formal-assurance-skills/skills/evidence.schema.json -> ../evidence.schema.json`. This makes a textual (non-symlink-aware) resolution of `../evidence.schema.json` from the compat skill dirs work too.
   - `skills/formal/wazir-formal-assurance-skills/README.md`: the upstream bundle README, verbatim. Its `skills/<s>/…` links work through the symlinks.
4. **Claude Code registration** (§2): `.claude/skills/{alloy-formal-modeling,gam,wazir-z3,wazir-dafny,wazir-scenic,wazir-verifai}/` and `.claude/skills/evidence.schema.json`, as plain copies of `skills/formal/`, byte-identical (26 files).
5. **Manifest + loader**:
   - `skills/formal/manifest.json`: for each tool id (`alloy`, `z3`, `dafny`, `scenic`, `verifai`, `gam`) it lists the frontmatter `name`, `dir`, `claudeDir`, aliases, priority, use, `taskTypes`, `skill` (SKILL.md), `references`, `examples`, `scripts` and `evals`. Paths are relative to `skills/formal/`. The four Wazir skills have no `references/*.md`, so their `references` list contains the shared `evidence.schema.json`, which their SKILL.md tells the agent to emit against.
   - `skills/formal/index.mjs`: `resolveSkill(key)` takes a tool id, task type, alias or frontmatter name, matched case-insensitively with spaces and `_` treated as `-`. The other exports are `getSkillPaths(key)`, `loadSkillContext(key, {references, examples})` (returns `{id, name, files, text}`; `text` is SKILL.md followed by the references, each under a `<!-- skills/formal/<path> -->` header, ready for worker context), `listSkills()` and `verifyManifest()`. `verifyManifest()` checks that every key maps to exactly one skill, that every listed path exists, that the frontmatter `name` matches, and that every `references/*.md` on disk is listed. CLI: `node skills/formal/index.mjs --list | --check | --paths <key> | <key> [--no-references] [--examples]`.
   - `skills/formal/index.test.mjs`: a vitest suite, which the root `vitest run` picks up.

## Path rewrites (the only deviations from verbatim)

- `{z3,dafny,scenic,verifai}/SKILL.md`: the example commands were relative to the bundle root (`python skills/z3/examples/…`). They are now `python examples/…`, with a `# Run from this skill's directory (e.g. skills/formal/<s>/ or .claude/skills/wazir-<s>/).` comment. The upstream form only worked from the bundle root; this one works in all three layouts.
- `z3/SKILL.md`: `../../evidence.schema.json` → `../evidence.schema.json`, with a note giving the in-repo locations. `../../` would have resolved to `skills/` and `.claude/`, both wrong.
- `scripts/validate_skills.py`: looks each skill up as `<root>/<name>`, `<root>/skills/<name>` or `<root>/wazir-<name>`. It adds `--root DIR` and `--check-mirror DIR`, which byte-compares `.claude/skills` against `skills/formal`, including file sets. The original assertions are unchanged.
- `alloy/` and `gam/` needed no rewrites: all their paths are skill-root relative, and `run-examples.sh` resolves its root from `BASH_SOURCE`. `gam/SKILL.md` refers to `npm run alloy:emit|alloy:check`, `src/core` and `docs/CORRECTIONS.md` in the **upstream GAM project**. Those don't exist in Wazir and were left verbatim.
