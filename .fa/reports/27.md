# Agent 27 Report — Assurance Record & Schema Validation (`fa/27-assurance-record`)

## Summary
Implemented `packages/assurance/src/record.ts` and unit tests in `packages/assurance/src/__tests__/record.test.ts` per `FORMAL_ASSURANCE.md` §2.7.

- **`generateAssuranceRecord`**: Aggregates `LedgerEntry[]`, `SpecManifest[]`, `RefinementMap`, and regression obligation counts for a given `component` and `sourceCommit` into a machine-readable `AssuranceRecord`.
  - Computes per-property `specification_consistency` (Alloy/GAM), `decision_envelope` (Z3), `implementation_contract` (Dafny + refinement capping via `capImplementationVerdict` and `applyTrustedBaseGaps`), `simulation_falsification` (VerifAI/Scenic), `runtime_monitor`, and weakest-link `overall`.
  - Explicitly includes `non_claims` and `not_claimed` (`["perception_correctness", "physical_dynamics_fidelity", "real_world_safety", "unbounded_temporal_liveness"]` + configurable additions).
  - Enforces via `preventNotFalsifiedPromotion` and `evaluateReleaseGate` that `NOT_FALSIFIED` is never promoted to `PROVED` or `BOUNDED_PASS` in the record or release gate.
- **`validateAgainstEvidenceSchema`**: Validates both portable evidence records (`ledgerEntryToPortableEvidence`) against `skills/formal/evidence.schema.json` and `AssuranceRecord` objects (checking required fields, non-claims, verdict enums, and non-promotion invariants).
- **YAML & JSON Serialization**: `serializeAssuranceRecordToYaml`, `serializeAssuranceRecordToJson`, `serializeAssuranceRecord`, and `parseAssuranceRecord`.
