## 2. Key Architectural Findings for Downstream Formal Assurance Agents

1. **Feasibility Set $F(t)$ Invariance Under Model Pinning (`packages/core/src/services/scheduler.ts` `L473–L516`, `L255–L257`)**:
   - Setting `task.execution.targetModelId` bypasses comparative score ranking (`strategy: 'explicit'`) but **never bypasses hard feasibility filtering** (`scoreModel` and `scheduleComputer`). If a pinned model violates capability, context, policy, or routing mode (`LOCAL_ONLY` / `PROVIDER_ONLY`) constraints, `Scheduler` throws `SchedulingError` immediately with no silent fallback.
   - Additionally, `Scheduler.plan()` (`L223–L229`) blocks external CLI agents (`source === 'external'`) whenever `routing.mode === 'PROVIDER_ONLY'` so delegated agents cannot bypass provider lock-in.

2. **Two-Level Lease Fencing & Unknown-Mutation Refusal**:
   - **Level 1 (`JobManager.acquire`, `packages/core/src/services/jobManager.ts` `L126–L191`)**: Before taking over a previously `RUNNING` job whose lease expired, `findUnknownMutationsByTask` (`L89–L124`) scans for any mutating tool call (`write_file`, `apply_patch`, `run_command`, `git_ops`) that recorded `tool.started` without a matching completion. If found, takeover is refused with `UNKNOWN_MUTATION_OUTCOME`.
   - **Level 2 (`ExecutionEngine.assertLease`, `packages/core/src/services/executionEngine.ts` `L1349–L1414`)**: Every mutating method on `ExecutionEngine` verifies `workerId`, monotonic `epoch`, cryptographic `token`, and `expiresAt > now` prior to mutating state, throwing `StaleWorkerLeaseError` (`STALE_WORKER_LEASE`) on mismatch.
   - **Storage Layer (`persistExecutionRecord`, `packages/core/src/services/executionPersistence.ts` `L17–L48`)**: Enforces `(record.storageRevision ?? 0) === (current?.storageRevision ?? 0) + 1` (`EXECUTION_STORAGE_CONFLICT`) and prefix-identity of `record.events` (`EXECUTION_HISTORY_CONFLICT`) inside atomic `store.update`.

3. **Defense-in-Depth Workspace Confinement**:
   - Path confinement is enforced at three independent layers: `PolicyEngine.resolveRealPath` (`packages/core/src/services/policyEngine.ts` `L275–L300`, walking up to the nearest existing ancestor via `fs.realpathSync`), `WorktreeManager` (`packages/core/src/services/worktreeManager.ts` `L41`, `L379–L420`, neutralizing git hooks via `-c core.hooksPath=/dev/null` and guarding worktree removal paths), and `SandboxExecutor` (`packages/tools/src/sandbox.ts`, OS-level `bwrap` / `sandbox-exec` write confinement).
