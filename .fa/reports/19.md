# Agent 19 — VerifAI adapter and monitor unit tests

Branch: `fa/19-verifai-adapter`

## Delivered
- `packages/assurance/src/adapters/verifai.ts`: `VerifAIAdapter` (`tool = 'verifai'`) implementing `SolverAdapter`.
  - `evaluateMonitorOnTraces(monitor, {passing, failing})`: a pure TS sanity check. It fails if the monitor misclassifies any known trace, returns NaN, or if either trace set is empty.
  - `verify()` always runs the monitor sanity check (Python mode, VerifAI `specification_monitor`) **before** any campaign. If the check fails, the result is `ERROR` and no campaign runs.
  - Headless campaign: an embedded Python runner (`VERIFAI_RUNNER_PY`) run with `tools/verifai-venv/bin/python3`. The interpreter is found by searching upward from cwd, or set with `WAZIR_VERIFAI_PYTHON` or the `pythonPath` option. It uses a seeded box sampler over `metadata.space`, or VerifAI `ScenicSampler` over `metadata.scenicFile`. It also re-runs every seed in `metadata.holdoutSeeds` (§2.5).
  - Capability flag `simulatorAvailable` (set on the constructor or per call) defaults to false. If `metadata.requiresSimulator` is set and the flag is off, the result is `NOT_RUN` and nothing is spawned. When the flag is on, the module must provide `run_simulator(params, seed)`; no simulated runs are made up.
  - Process runner can be injected so verdict mapping can be tested without Python.
- `packages/assurance/src/__tests__/verifai-adapter.test.ts`: 20 tests, all passing (`npx vitest run packages/assurance/src/__tests__/verifai-adapter.test.ts`).
  - Monitor unit tests on known passing and failing traces (TS).
  - Verdict mapping with a fake runner: NOT_RUN (simulator flag off, Python missing, VerifAI not importable), ERROR (sanity check fails, no traces), UNKNOWN (timeout), NOT_FALSIFIED (budget exhausted).
  - Real VerifAI 2.2.0, no simulator: FALSIFIED with a replayable witness (the same seed gives the same witness), NOT_FALSIFIED across holdout seeds 1/101/202, ERROR for a monitor that always passes. These tests are skipped automatically if the venv is missing.

## Verdict mapping
| Outcome | Verdict |
|---|---|
| rho < 0 on any primary or holdout sample | `FALSIFIED`; witness = {seed, sampleIndex, params, trace, rho, holdout} |
| Budget exhausted, rho >= 0 everywhere | `NOT_FALSIFIED` (never `PROVED` / `BOUNDED_PASS`) |
| Monitor misclassifies a known trace / no known traces / runner crash / missing artifact or space | `ERROR` |
| Timeout, or a seed with 0 samples | `UNKNOWN` |
| Python/VerifAI missing, or simulator required with capability off | `NOT_RUN` |
