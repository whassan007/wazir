## Probed Alloy 6.2.0 output (facts the parser depends on)
- `receipt.json` → `commands[<name>]` with `type` (`run`/`check`), `source`, `overall` (scope), `bitwidth`, `maxprefix` (steps, -1 if not temporal), `expects`.
- A **SAT** command has a `solution` array (`solution[0].instances[0]` = instance, including skolems). An **UNSAT** command has **no** `solution` key.
- The text trace goes to `<name>-solution-0.txt` (only for SAT commands). Anonymous commands are named `run$1`, etc.
- Exit code 0 covers both SAT and UNSAT checks. Syntax and type errors exit 1 with no receipt.

## Verdict mapping
| Condition | Verdict |
|---|---|
| any targeted `check` SAT | `COUNTEREXAMPLE` (witness: command, source, receipt instance, text trace) |
| all targeted checks UNSAT + vacuity probe passes | `BOUNDED_PASS` (never `PROVED`) |
| all targeted checks UNSAT + probe fails | `INCONSISTENT_ASSUMPTIONS` (via `applyVacuityProbe`) |
| timeout (SIGKILL) | `UNKNOWN` |
| nonzero exit / missing or bad receipt / model missing / targeted check not found / no checks | `ERROR` |
| JAR missing, `java` ENOENT | `NOT_RUN` |

Vacuity probe: witnesses are `obligation.metadata.witnessCommands` if set (all must be SAT). Otherwise they are every `run` not marked `expect 0`, and at least one must be SAT. A model with no run witness fails the probe.
`obligation.command` holds the comma-separated check names to judge. Empty or `*` judges every check.

Recorded fields: `toolVersion` 6.2.0 (pinned; `checkAvailability()` reads the real version via `jar version`), `elapsedMs`, `inputHash` (sha256 over model hash + command + scope + workspaceRev), `scope` (per-command source + overall/int/steps; `obligation.scope` overrides), `metadata.intBitwidth`, `metadata.steps`, `metadata.commands`, stdout/stderr.
