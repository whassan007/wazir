## What downstream agents import (`@wazir/assurance`)

**Contracts (`contracts.ts`):**
- `Verdict`: a string enum that is both a value and a type, with all 11 verdicts. `ALL_VERDICTS` lists them.
- `FormalTool` and `FORMAL_TOOLS`.
- Interfaces: `VacuityProbeResult`, `Obligation`, `VerificationResult` (aliased `Result`), `SolverAdapter` (aliased `Adapter`), `ToolAvailability` and `VerifyOptions`.
- Spec registry (§2.2): `SpecStatus`, `SPEC_STATUSES`, `SpecSource`, `SpecArtifact`, `SpecMonitor` and `SpecManifest`. Field names are snake_case, matching the YAML.
- Refinement mapping (§2.6): `RefinementProductionMode`, `RefinementMappingEntry` and `RefinementMap`.
- Ledger and assurance records (§2.7):
  - `LedgerEntry`: `index`, `prevHash`, `entryHash`, `timestamp`, property/spec hash, commit/revision, tool and version, `inputHash`, scope/bounds/steps, assumptions, verdict, `witness`/`unsatOutcome`, `elapsedMs`, `seeds`, `artifactHashes` and an optional `fencingToken`.
  - `PropertyAssuranceSummary`, `AssuranceRecord`, `ReleaseGateResult` and `RuntimeMonitorStatus`.

**Verdict model (`verdict.ts`):**
- `NATIVE_VERDICT_MAPPING`: a lookup table from each tool's native outcome to a `Verdict`. `mapNativeOutcomeToVerdict(native)` takes a per-tool input object (one shape per tool, chosen by the `tool` field).
  - **Z3** (queries `A ∧ impl ∧ ¬P`): `sat` → COUNTEREXAMPLE. `unsat` → PROVED, or BOUNDED_PASS when `bounded: true`. `unknown`/`timeout` → UNKNOWN.
  - **Alloy:** `counterexample` → COUNTEREXAMPLE. `no_counterexample` → BOUNDED_PASS. Alloy never returns PROVED.
  - **Dafny:** `verified` with no trusted-base gaps → PROVED. `verified` with gaps → BOUNDED_PASS under `gapPolicy: 'downgrade'` (the default) or NOT_VERIFIED under `'block'`. `assertion_violation` → COUNTEREXAMPLE. Parse and type errors → ERROR.
  - **Scenic / VerifAI:** `violation` → FALSIFIED. `sampled`/`exhausted` → NOT_FALSIFIED. `incomplete`/`sampling_exhausted` → UNKNOWN. Neither tool can produce a pass.
  - **GAM:** `consistent && satisfied` → BOUNDED_PASS. Any `false` → COUNTEREXAMPLE. Consistent with the ontology check not run → UNKNOWN. Neither check run → NOT_RUN.
  - **Every tool:** `not_run` → NOT_RUN and `error` → ERROR. Any unrecognised outcome or tool → ERROR (fail closed).
- `preventNotFalsifiedPromotion(from, to)` throws `VerdictPromotionError` for NOT_FALSIFIED → PROVED/BOUNDED_PASS.
- `applyVacuityProbe(verdict, probe?)` turns PROVED/BOUNDED_PASS into INCONSISTENT_ASSUMPTIONS unless `probe?.passed === true`.
- `applyTrustedBaseGaps(verdict, gaps)` turns PROVED with gaps into BOUNDED_PASS.
- `capImplementationVerdict(verdict, production)` (§2.6) turns a pass into NOT_VERIFIED unless `production` is `compiled_from_dafny` or `refinement_proof`.
- `VERDICT_WEAKEST_LINK_ORDER`, weakest first: COUNTEREXAMPLE < FALSIFIED < INCONSISTENT_ASSUMPTIONS < ERROR < SPECIFICATION_REVIEW_REQUIRED < UNKNOWN < NOT_RUN < NOT_VERIFIED < NOT_FALSIFIED < BOUNDED_PASS < PROVED. Helpers: `verdictStrength` and `weakerVerdict`.
- `aggregateVerdictsWeakestLink(verdicts)` returns the minimum under that order. An empty list gives NOT_RUN and an unrecognised verdict gives ERROR.
- `evaluateReleaseGate(verdicts, specApproved)` returns `{status, reason?}`. It is FAIL in any of these cases:
  - the spec is not approved;
  - the verdict list is empty;
  - a verdict is unrecognised;
  - any verdict is in `RELEASE_BLOCKING_VERDICTS`;
  - there is no PROVED/BOUNDED_PASS (for example, only NOT_FALSIFIED).
- Also exported: `PASSING_VERDICTS` and `isPassingVerdict`.

## Assumptions and open questions

- `Verdict` is a TS string enum, so its values equal its names and serialise as plain strings in the ledger and YAML.
- The Dafny gaps default is `downgrade` → BOUNDED_PASS, which follows §2.3's "gaps block PROVED". Adapters that want gaps to fail the release should pass `gapPolicy: 'block'`.
- `LedgerEntry` hashing fields (`prevHash`, `entryHash`, `index`) are named here, but the hashing algorithm and canonicalisation belong to the ledger agent.
- The package has no dependencies, so it can be imported by `core` or any adapter without a cycle.
