# Agent 18 — Scenic adapter

Implemented headless ScenicAdapter against the C0 SolverAdapter contract. Only the three owned paths were changed; src/index.ts was not edited.

Implementation commit: e111830
Tests commit: 38748fc

The adapter uses /Users/wael/Code/Wazir/tools/scenic-venv/bin/python3 by default, checks the Scenic import/version, seeds Python and NumPy, and uses the Agg backend without visualization or simulation. Constructor options configure pythonPath, seed, count, maxIterations and maxRejectionRate (default 0.95). Obligation.seed overrides the configured seed; obligation.metadata can override the sampling count, per-scene iteration cap and rejection threshold. Timeout comes from VerifyOptions.timeoutMs, then Obligation.timeoutMs, then 60 seconds.

Results retain attempted/generated/rejected counters, seed, Scenic version, input hash, workspace revision, stdout/stderr and serialized scene objects (positions/headings) and parameters in both metadata.scenes and witness. Attempts include each successful scene's reported iterations and the full per-scene cap when sampling is exhausted. The vacuity probe fails if generation is incomplete or rejected/attempted exceeds the configured threshold. Successful generation returns only NOT_FALSIFIED; failed probes return INCONSISTENT_ASSUMPTIONS. Missing Python/Scenic returns NOT_RUN, parse/bridge errors return ERROR, and execution timeout returns UNKNOWN.

- Deterministic replay and changed-seed witnesses, serialized fields, complete rejection, excessive rejection despite complete generation, invalid settings, missing executable and missing-package capability checks are covered.

Limits: headless generation checks Scenic's generation requirements only, not dynamic simulation monitors. Arbitrary parameter values without a native JSON representation are serialized as strings. The adapter does not provide process sandboxing or enforce memory limits; those remain execution-layer responsibilities. Availability probing has a separate 10-second deadline. Sampling counters/scenes are returned after the bridge completes; an interrupted process cannot return partial sampling evidence. Runtime version is recorded rather than compared against a configured version allowlist.
