## Notes / decisions
- **Hash algorithm (new; the repo had none):** sha256 over sorted `"<file>\n<sha256(bytes)>\n"` records for the manifest (with `content_hash` set to `""`) and every listed artifact/monitor file. Downstream registry code should reuse `compute_hash.py --check` or copy the same algorithm.
- **Mutants:** in Alloy, the mutant is the `crossUnguarded` action (stop guard removed), checked by `NoCrossOnRedMutant`. In Z3, `mutant` doubles the dilemma-zone threshold (one guard relaxed). My first Z3 mutant (dropping the margin) made the guard *stricter* and came back PROVED, so I replaced it.
- The manifest lists only `WitnessStop` and `NoCrossOnRed` as Alloy commands. The negative-control `NoCrossOnRedMutant` is in the `.als` file but should be run as a separate step that is expected to fail.
- z3 Python bindings are present for `/opt/homebrew/bin/python3` only (not the default miniforge `python3`). Adapters should pick their interpreter with this in mind or report `NOT_RUN`.
- No `manifest.json` was added, so there is only one source of truth.
- Everything here is a toy model, not a certified braking or traffic-law model.
