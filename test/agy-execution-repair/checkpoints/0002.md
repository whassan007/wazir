# Checkpoint 0002

## Action
Implemented P0-A (scoped verification) in full:
- `packages/tools/src/process-tools.ts`: `makeCheckTool` accepts `workspaces?: string[]`, appends
  `--workspace <name> --if-present` per workspace to the npm invocation instead of always running the
  root script.
- `packages/agents/src/verificationScope.ts` (new): `resolveVerificationScope(projectRoot,
  changedFiles)` maps changed files to the workspace package(s) that own them (mirrors this repo's
  `packages/*`, `packages/runtimes/*`, `apps/*` workspace globs); reports `fullScopeRequired` when any
  changed file falls outside every known workspace.
- `packages/agents/src/codingAgent.ts` VERIFY phase: computes scope, runs checks with `{workspaces:
  [...]}` when safe, falls back to the full unscoped run when `fullScopeRequired`, no workspace
  resolved, or the caller explicitly set `fullVerification: true`. Emits a `message` turn reporting the
  scope decision and justification (satisfies "report skipped checks and justification").
- `packages/core/src/types/agent.ts`: added `AgentRunRequest.fullVerification?: boolean`.
- `apps/cli/src/run.ts`, `commands.ts`, `index.ts`: threaded a new `wa run --full-verify` flag through
  to the agent request.
