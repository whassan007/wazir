# Wazir Extension SDK

`packages/core/src/sdk/index.ts` defines stable extension contracts (`WazirExtensionManifest`, `WazirExtensionPlugin`, `WazirExtensionRegistry`) keeping domain-specific ontologies, workflows, rubrics, quality gates, tools, dashboards, and reports outside Wazir Core.

Built-in reference extensions:
1. `lorecraft`
2. `90nf-forge`
3. `bazaar`
4. `robotics-simulation`
5. `research-evaluation`
6. `software-development`
