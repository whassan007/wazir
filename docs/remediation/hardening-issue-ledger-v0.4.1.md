# Wazir v0.4.1 Hardening & Qualification Issue Ledger

| ID | Severity | Subsystem | Issue | Fix & Verification | Status |
|---|---|---|---|---|---|
| `HARD-01` | **P0** | `packages/core` | `CoordinationFabric`, `MessageRouter`, `ResourceReservationManager`, and `coordination.ts` types were not exported from `@wazir/core`, and `jobOrchestrator.ts` failed `tsc --build` (`payload` required in `CoordinationPublishInput`). | Exported all coordination types/services from `packages/core/src/types/index.ts` and `services/index.ts`; made `payload` optional in `CoordinationPublishInput` and defaulted to `{}`. Verified with `npm run typecheck`. | **FIXED** |
| `HARD-02` | **P0** | `packages/core` | `JobOrchestrator` did not wire `ResourceReservationManager` lease acquisition/renewal/fencing or `MessageRouter` agent clients during `doPump()` task execution. | Wired `resourceReservations.acquire` (with contention deferral), periodic `renew`, `validateFence` before `completeTask`, `release` in `finally`, `messageRouter.createAgentClient`, and lifecycle events. | **FIXED** |
| `HARD-03` | **P1** | `packages/core` | `ResourceReservationManager.canonicalizePath` did not resolve dangling symlinks, allowing two aliases to the same nonexistent target to bypass `pathsOverlap` conflict detection. | Added `lstatSync` + `readlinkSync` recursive resolution with depth guard (32). Verified in `resourceReservationManager.test.ts`. | **FIXED** |
| `HARD-04` | **P1** | `packages/core` | `MessageRouter` had unbounded inbox growth and crashed on corrupted `inbox.json` / `_router_state.json`. | Added `maxInboxSize` (4096) with `InboxBackpressureError` and corrupt JSON quarantine recovery. Verified in `messageRouter.test.ts`. | **FIXED** |
| `HARD-05` | **P1** | `apps/shell`, `apps/desktop` | `tauri.conf.json` had `"csp": null` in both Tauri apps; `apps/shell` did not kill/reap PTY child processes on `pty_close`; `apps/shell/ui/index.html` used `innerHTML` for About modal. | Added strict CSPs to both `tauri.conf.json` files, stored and killed/waited `child` in `PtySession`, enforced `MAX_PTY_SESSIONS = 32`, and replaced `innerHTML` with `textContent`. | **FIXED** |
| `HARD-06` | **P1** | `apps/desktop`, `release.yml`, `release-gate.mjs` | `apps/desktop/package.json` returned exit 0 on skipped/null build; `release.yml` hardcoded `draft: false`; `release-gate.mjs` accepted stale cached evidence without source/commit/bundle validation. | Fixed `apps/desktop/package.json` to fail closed, wired `inputs.publish_draft` and `--strict --verify-only` in `release.yml`, and added `validateCachedEvidence` in `release-gate.mjs`. | **FIXED** |
| `HARD-07` | **P1** | `scripts/generate-release-manifest.mjs` | Equated SHA-256 with signing and generated SBOM from root `devDependencies`. | Separated `signingStatus` from `integrity: 'sha256'`, added provenance & stale-artifact pruning, and generated CycloneDX 1.5 SBOM from `package-lock.json`, `Cargo.lock`, and bundled model assets (767 components). | **FIXED** |
| `HARD-08` | **P2** | `apps/portal`, `docs/` | `apps/portal` lacked `_headers` CSP, graceful missing-manifest handling, iOS/Windows-ARM64 clarity; `README.md` claimed Windows ARM64 was `VERIFIED` while `release-gate.mjs` marked it `UNSUPPORTED`. | Added `apps/portal/_headers`, manifest-unavailable fallback, iOS & Windows 11 ARM64 Preview status, and reconciled `README.md`, `docs/compatibility-matrix.md`, and `apps/mobile/README.md`. | **FIXED** |
