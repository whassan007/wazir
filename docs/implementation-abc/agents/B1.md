## Summary of Changes

### 1. Backward-Compatible Extension of `ModelIntelligenceService` (`packages/core/src/services/modelIntelligenceService.ts`)
- Exported `HarnessProfileSegmentationKey extends ProfileSegmentationKey` (`harnessId?: string; environment?: string; environmentKey?: string`) and `HarnessModelCapabilityProfile extends ModelCapabilityProfile`.
- Preserved the exact 5-part key `${model}::${version}::${runtime}::${quant}::${proto}` when `harnessId` is omitted so all existing `modelIntelligence` and `modelIntelligenceGates` unit tests pass unchanged.
- Appends `::${harnessId}` (and `::${environment}` when provided) when `harnessId` is present, and scopes configuration drift checks to matching `harnessId` so distinct harnesses using the same model/runtime never collide or trigger false drift warnings.

### 2. Implementation of `HarnessPerformanceService` (`packages/core/src/services/harnessPerformanceService.ts`)
- **Segmented Tracking**: Tracks empirical performance profiles by `(harnessId, modelId, runtimeId, taskCategory, environment)` while reusing `ModelIntelligenceService` and `TaskCapabilityClassifier`.
- **Independent Physical Verification Invariant**: Only increments `verifiedSuccessCount` when independent controller verification passed (`verified === true` with no errors or non-stale checks, or passing physical checks at the final `workspaceRevision`). Self-reported completion (`status: 'completed'`) without verification is recorded as `unverified_completion` / `codingFailureCount`.
- **Provider/Infrastructure Outage Separation**: `isProviderInfrastructureOutage` isolates HTTP 429 rate limits, `ECONNREFUSED`, gateway 502/503/504 errors, timeouts before model response, `errorKind === 'infrastructure'`, and `PROVIDER_OUTAGE` into `providerOutageCount` and `availabilityRate`, never conflating outages into `codingFailureCount`, `verifiedSuccessRate`, or `capabilityScore`.
- **Deduplication & Retry Accounting**: Deduplicates by `(executionId, attemptId)` and tracks `retryCount`, `firstAttemptSuccess` (`firstAttemptSuccessCount`, `firstAttemptSuccessRate`), and `eventualVerifiedSuccess` (`eventualVerifiedSuccessCount`, `eventualVerifiedSuccessRate`) without double-counting `sampleCount`.
- **Statistical Uncertainty & Cost/Latency Metrics**: Computes 95% Wilson score confidence intervals (`uncertainty: { lowerBound, upperBound, width, confidenceLevel }`), `avgCostUSD`, `costPerVerifiedSuccessUSD` (preserving `undefined` when `costStatus === 'UNKNOWN'`), and `avgDurationMs` / `p50DurationMs` / `p95DurationMs`.
- **Staleness & Insufficient Evidence Detection**: Flags `isStale` and `staleReason` on version/protocol/quantization/environment drift or when age exceeds `maxAgeMs`, and flags `insufficientEvidence` / `hasSufficientEvidence` against `minSamples`.
- **Durable Persistence**: Persists profiles and execution deduplication state to `KeyValueStore` under `harness-perf/<segmentKey>` and restores them on `ready` / `restore()`.
