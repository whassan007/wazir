## Summary of Implementation

### 1. Portable Checkpoint & Handoff Schema (`packages/core/src/types/portableCheckpoint.ts`)
- Defined `PORTABLE_CHECKPOINT_SCHEMA_VERSION = 1` and `PORTABLE_HANDOFF_SCHEMA_VERSION = 1`.
- Implemented `PortableBudgetState`, `PortableRemainingBudget`, `PortableActionSummary`, `PortableHandoff` (matching `SHARED-CONTRACTS.md`), and `PortableCheckpointEnvelope`.
- Implemented `computeWorkspaceContentDigest(filesSnapshot, workspaceRevision)` matching `CheckpointService.computeDigest` byte-for-byte.
- Implemented `computePortableCheckpointDigest(envelope)` (and alias `computePortableHandoffDigest`) using canonical recursive key-sorting and ISO date normalization so digests remain invariant across `JSON.stringify` / `JSON.parse`.
- Implemented `classifyPortableResumability` to enforce non-resumable classification with explicit `nonResumableReason` when:
  - Execution is in a terminal `'completed'` or `'cancelled'` state.
  - Any non-`READ_ONLY` tool call in `unresolvedSideEffects` is in `'STARTED'` or `'OUTCOME_UNKNOWN'` state.
  - Any budget dimension in `remainingBudget` (`maxTokens`, `maxToolCalls`, `maxModelCalls`, `maxCostUSD`, `maxDurationMs`) is exhausted (`<= 0`).
- Implemented `validatePortableCheckpoint` and `assertValidPortableCheckpoint` to verify:
  - Schema version compatibility (`schemaVersion === 1`).
  - Required structural fields and types.
  - Unsafe snapshot path rejection (`..`, absolute paths, `.git`, `.wazir`, `node_modules`, null bytes, backslashes).
  - Resumability invariants (rejecting forged `resumable: true` when blocking side effects or exhausted budgets exist).
  - Cryptographic `workspaceContentDigest` and outer `integrityDigest`.
- Implemented `redactPortableText` and `redactPortableValue` to scrub API keys, bearer tokens, URL credentials, PEM blocks, and secret key-value pairs prior to serialization.
- Implemented `toPortableHandoff(envelope)` to extract a canonical `PortableHandoff` with its own `integrityDigest`.

### 2. CheckpointService Extensions (`packages/core/src/services/checkpointService.ts`)
- Added `exportPortableCheckpoint(checkpointId, options?)`:
  - Extracts confirmed actions (tool calls, file mutations, verification checks), unresolved tool call side effects, verification evidence IDs, consumed and remaining budgets, and policy requirements (`PolicyRequirements`).
  - Redacts secret/token material from objectives, action summaries, pending actions, tool inputs, and metadata.
  - Computes and binds `workspaceContentDigest` and `integrityDigest`.
- Added `importPortableCheckpoint(envelope, options?)`:
  - Validates schema version, resumability invariants, path safety, `workspaceContentDigest`, and `integrityDigest`.
  - Reconstructs and persists `ExecutionCheckpoint` to `CheckpointService` (including durable `KeyValueStore` persistence and portable metadata preservation for round-trip re-export).
  - Optionally materializes the verified workspace snapshot onto `options.targetWorkspaceRoot`.
