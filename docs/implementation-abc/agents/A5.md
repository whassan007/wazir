## Mission Summary

Implemented a deterministic local ACP agent fixture (`deterministicAcpFixture.ts`) and a comprehensive 12-scenario Cross-Harness Conformance & Security Suite (`harnessConformance.test.ts`) that qualifies both Wazir-native execution (`CodingAgent`) and external ACP execution (`AcpAgentAdapter` / `AcpClientAdapter`) against the Group A `UnifiedExecutionRequest` / `UnifiedExecutionResult` contract, `PolicyEngine`, and `VerificationEngine` without requiring paid model credentials.

## Deterministic ACP Fixture (`packages/agents/tests/fixtures/deterministicAcpFixture.ts`)

Supports both in-memory `AcpConnectionLike` test-seam injection (`mode: 'in-memory'`) and real child-process stdio execution via `node --input-type=module -e` (`mode: 'stdio'`) across 7 deterministic scenarios:
1. `normal-completion`: Streams `plan`, `tool_call`, requests one-shot `edit` permission (`allow_once`), writes target artifact in `cwd`, emits `tool_call_update` (`completed`), suppresses `agent_thought_chunk`, streams `agent_message_chunk`, and completes turn with `end_turn`.
2. `malicious-always-permission`: Requests permission with only `allow_always` escalation, requests `execute` (`rm -rf /`), and requests `delete` on outside/protected paths.
3. `malformed-output`: Emits malformed/corrupted `session/update` notifications (`null`, primitives, unknown `sessionUpdate` types, non-array plan entries) followed by a valid completion chunk.
4. `crash-mid-turn`: Emits partial turn updates and terminates mid-turn with exit code `137` / `SIGKILL`.
5. `hang-until-cancelled`: Spawns a child process, records both parent and child PIDs when configured, and hangs until cancelled or forcibly reaped by process-tree termination.
6. `false-verification-claim`: Writes an unverified/buggy file and claims `"All tests passed! Verified 100%"` in its output text.
7. `unsupported-capability`: Advertises an incompatible protocol version (`9999`) or refuses session creation.
