## Summary of Changes

1. **External Harness Capability Discovery & Environment Sanitization (`packages/agents/src/acp/acpHarnessCapabilities.ts`)**:
   - Defined preset external harness profiles (`EXTERNAL_HARNESS_PRESETS` and `getExternalHarnessPreset`) for:
     - `qwen-code` (`qwen --acp` over ACP)
     - `codex` (`codex --acp` over ACP)
     - `claude-code` (`claude --acp` over ACP)
     - `opencode` (`opencode run` over stdio-cli)
     - Generic ACP / external CLI harnesses
   - Kept `supportedTaskTypes: []` on external presets so external harnesses are never auto-selected for unpinned tasks without explicit routing preference.
   - Implemented `sanitizeHarnessEnvironment` and `ALLOWED_ENV_KEYS` to allow only safe baseline environment variables plus explicit `spec.allowedEnvKeys`, stripping unauthorized secrets (`AWS_SECRET_ACCESS_KEY`, `GITHUB_TOKEN`, `DATABASE_PASSWORD`, etc.).
   - Implemented `discoverExternalHarnessCapabilities(spec, options)` to check binary availability (`BINARY_NOT_FOUND`), ACP protocol version compatibility (`ACP_PROTOCOL_INCOMPATIBLE`), environment blockers (`ENVIRONMENT_BLOCKED`), and permission mode ceiling clamping (`read` < `edit` < `full`).

2. **Unified External Harness Adapter (`packages/agents/src/externalHarnessAdapter.ts`)**:
   - Implemented `ExternalHarnessAdapter` supporting both ACP (`AcpClientAdapter`) and CLI subprocess (`resolveExternalCommand` + `spawnGroupWatchdog`) harnesses via `execute(request: UnifiedExecutionRequest): Promise<UnifiedExecutionResult>` and `AgentAdapter.run(...)`.
   - Enforced Wazir security and policy invariants:
     - Never selects `always` permission escalations; filters out `always` options and evaluates every ACP tool permission request against `protectedPaths`, `policyContext.networkAccess`, `PolicyEngine`, `policyEvaluator`, and `AcpPermissionMode`.
     - Bounds stdout/stderr capture (`MAX_EXTERNAL_OUTPUT_CHARS = 20_000`) to prevent runaway child output from exhausting memory.
     - Never self-certifies completion (`verified: false` unless an independent controller `verifyHook` confirms physical checks at the resulting `workspaceRevision`).
     - Defaults monetary cost for unpriced/subscription external harnesses to `costStatus: 'UNKNOWN'` and `costUSD: undefined` (never coerced to `0`).
     - Classifies missing binaries (`BINARY_NOT_FOUND`), ACP protocol mismatches (`ACP_PROTOCOL_INCOMPATIBLE`), policy denials (`PERMISSION_DENIED`), timeouts (`TIMEOUT`), cancellations (`CANCELLED`), and signal/subprocess crashes (`status: 'interrupted'`, `SUBPROCESS_INTERRUPTED`).

3. **Unit Tests (`packages/agents/tests/externalHarnessAdapter.test.ts`)**:
   - Added 14 unit tests covering preset definitions, environment secret stripping, capability discovery, ACP streaming & tool call normalization, independent `verifyHook` verification gating, never granting `always` permissions, `protectedPaths` and `policyEvaluator` denials, bounded output buffers, `ENOENT` handling, incompatible ACP protocol version handling, OpenCode CLI execution, subprocess signal crash classification, and mid-turn cancellation.
