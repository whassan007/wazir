## 2. Key Capabilities & Contract Compliance

1. **Canonical Task Suite (`CANONICAL_ROUTER_BENCHMARK_TASKS`)**:
   - 21 independently specified benchmark tasks (`>= 20`) spanning all 7 `BenchmarkTaskCategory` values (`CODE_REPAIR`, `FEATURE_IMPLEMENTATION`, `REPOSITORY_NAVIGATION`, `CODE_INTELLIGENCE`, `TOOL_USE`, `CONTEXT_STRESS`, `RECOVERY`) and all 3 difficulty levels (`easy`, `medium`, `hard`).
2. **Matched Conditions Enforcement**:
   - Computes SHA-256 digests over task definitions (`taskSuiteHash`), hardware eligibility / environment state (`environmentHash`), and execution budgets (`budgetHash`), throwing `MATCHED_CONDITIONS_VIOLATION` if baseline and candidate runs diverge on any condition.
3. **Physical Verification via `EvaluationService`**:
   - Every completed task execution is scored through `EvaluationService.evaluate(..., { requirePhysicalVerification: true })`. Apparent completions (`status: 'completed'`) without passing physical verification checks at the active workspace revision are marked `verified: false`.
4. **Seven Required Router Metrics + Statistical Uncertainty**:
   - Computes `verified_success_rate`, `cost_per_verified_success`, `end_to_end_latency_p50`, `end_to_end_latency_p95`, `retry_rate`, `fallback_rate`, and `policy_violation_rate` for both baseline and candidate policies, alongside sample counts, mean, variance, standard deviation, standard error, 95% confidence intervals (Wilson score interval for proportions; Student-t for continuous metrics), p50/p95 percentiles, and paired sign-test p-values.
5. **Blocked vs. Completed Separation**:
   - Distinguishes `status: 'COMPLETED'` from `status: 'BLOCKED'` (e.g., when required runtime or GPU/VRAM hardware is unavailable), recording blocked tasks separately without counting them as verified completions.
6. **Honest Reporting Invariant & Report Serialization**:
   - Reports `verdict: 'IMPROVEMENT' | 'NO_SIGNIFICANT_IMPROVEMENT' | 'REGRESSION'` honestly based on confidence interval overlap, paired sign tests, and zero-regression checks on `verified_success_rate` and `policy_violation_rate`.
   - Provides `toMarkdownReport(result)` and `toJsonReport(result)`.
