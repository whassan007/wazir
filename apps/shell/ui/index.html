Diagnostic Telemetry & Privacy

Diagnostic telemetry is strictly optional and disabled by default.

  • If enabled: Only sanitized crash/error metadata (version, OS/arch, error code, component, random installation ID) is recorded locally.
  • Never collected: Raw shell histories, prompts, source files, environment variables, API keys, tokens, or private paths.
  • If declined: Zero diagnostic events are recorded or uploaded, and all shell & AI features remain 100% functional.
