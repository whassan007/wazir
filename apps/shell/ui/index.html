Wazir Shell — Terms & Diagnostic Disclosure (v2026-11-20.1)

Before enabling diagnostic telemetry, please review:

  • Licensing: Existing Wazir Core/CLI/Desktop components are licensed under AGPL-3.0-only. Commercial authorization is required for commercial use of Wazir-branded noncommercial modules.
  • Minimum Diagnostics: If accepted, only sanitized crash/error metadata (version, OS/arch, error code, component, random installation ID) is collected.
  • Never Collected: Raw shell histories, prompts, source files, env vars, API keys, tokens, or private paths.
  • Declining: Declining keeps telemetry completely disabled (zero events sent) and never blocks your native OS shell.
