# `apps/mobile` — Archived / Superseded Scaffold

**Status:** **SUPERSEDED / UNMAINTAINED**

`apps/mobile` is an early v0.1.0 Expo / React Native native-shell scaffold (`io.wazir.missioncontrol`) containing only `android/` and `ios/` native project directories without a `package.json` or JavaScript/TypeScript application entrypoint.

It has been **superseded** by the two maintained native mobile companions:
- **Android / GrapheneOS (`ai.wazir.mobile`)**: [`apps/android/`](../android/) — Kotlin + Jetpack Compose + OkHttp SSE + Room + Android Keystore/BiometricPrompt.
- **iOS (`ai.wazir.mobile`)**: [`apps/ios/WazirMobile/`](../ios/WazirMobile/) — Swift + SwiftUI + URLSession + Keychain + LocalAuthentication.

`apps/mobile` is retained in the repository for historical reference only and is excluded from active builds and release artifacts.
