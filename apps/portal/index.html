Complete platform reference for Wazir AI OS.

Quickstart & Platform Install

Install via verified .dmg, .deb, .rpm, Homebrew, or Termux ARM64. Run wa doctor to verify local runtimes.

Configuration & Commands

Use wa shell, wa exec, wa fleet, wa about, wa license, and wa diagnostics. Configure endpoints in ~/.wazir/config.json.

Distributed Execution & Workers

Register workers with WAZIR_REGISTRATION_TOKEN over SSE + lease-fenced execution claims (POST /computers/:id/executions/:id/claim).

Model Provider Setup

Supports Ollama, MLX, LM Studio, vLLM, and authorized remote providers with local-first routing and hardware capability matching.

Security Model & Sandboxing

Realpath workspace containment, PolicyEngine command classification, bearer-token & device-scoped auth, and zero unauthenticated remote shell exposure.

Troubleshooting & Releases

Run wa doctor --detail to inspect runtime health, or review release notes and known limitations in the Downloads section.

Telemetry & Diagnostics Policy

Affirmative Consent Only: Wazir never sends telemetry before explicit acceptance on first launch. Declining disables diagnostics completely without blocking your native OS shell.

Minimum Schema: App version, OS family/arch, error code, failure category, component ID, sanitized exception category, task phase, worker capability, safe model category, timestamp, and random installation ID. Raw shell histories, source files, prompts, env vars, API keys, tokens, and private paths are redacted and never collected by default.
