Privacy & diagnostics

Zero telemetry before affirmative acceptance. Declining diagnostic reporting disables event collection completely and never blocks your native OS shell.

When enabled, only allowlisted metadata (app version, OS/arch, error code, failure category, component ID, random installation ID, consent version) is collected. Raw shell histories, prompts, source files, API keys, tokens, and private paths are stripped by redactDiagnosticPayload() and never collected by default.
