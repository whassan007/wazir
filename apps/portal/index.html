Privacy & diagnostics

Zero telemetry before acceptance. Declining diagnostic reporting disables event collection completely and never blocks your native shell.

When enabled, only allowlisted metadata (app version, OS/arch, error code, component ID, random installation ID) is collected. Raw shell histories, prompts, source files, API keys, tokens, and private paths are stripped and never collected by default.
