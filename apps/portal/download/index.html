System requirements & installation instructions
  • macOS 14+ (Apple Silicon / Intel), Ubuntu 24.04+ / Debian / Fedora, or Windows 11 (x64 / ARM64)
  • Node.js 22.13+ for CLI/worker runtime (built-in node:sqlite ledger)
  • Verify checksum: shasum -a 256 -c SHA256SUMS.txt --ignore-missing
  • Verify install: wa about && wa doctor && wa route "explain chmod 755"
  • Note: macOS archives are unsigned development builds — run xattr -cr "/Applications/Wazir Shell.app" if Gatekeeper prompts.

Upgrade & rollback

          
Configuration and consent records in ~/.wazir are preserved across upgrades and rollbacks.

          
# Debian/Ubuntu upgrade or rollback:
sudo dpkg -i wazir_<version>_all.deb

# Source build pin / rollback:
git checkout v0.4.0 && npm install && npm run build

        

        

          
Installer troubleshooting

          
    
            
  • macOS Gatekeeper: Unsigned development bundles require clearing quarantine once: xattr -cr "/Applications/Wazir Shell.app".
    • 
            
  • Node.js runtime: CLI/worker requires Node.js >= 22.13.0. Run wa doctor --detail to verify runtimes.
    • 
            
  • Checksum mismatch: Re-download from SHA256SUMS.txt and do not install modified packages.
