System requirements & installation instructions
  • macOS 14+ (Apple Silicon) or Ubuntu 24.04+ / Debian / Fedora
  • Node.js 22.13+ for CLI/worker runtime
  • Verify checksum: shasum -a 256 -c SHA256SUMS.txt
  • Note: macOS archives are unsigned development builds (no Apple Developer ID notarization yet).

Wazir on your phone

GrapheneOS & Android · Zero-root companion

Download GrapheneOS / Android APK (v0.3.2) Install Termux ARM64 CLI
Secure pairing
Scan or open wazir-portal.pages.dev/download on GrapheneOS, then pair via scoped URI/QR token in Mission Control.
Supported Android versions & permissions
  • Android 8.0+ / GrapheneOS (API 26–35, ARM64)
  • Never requires root access; respects GrapheneOS storage & network scopes
  • APK is debug-signed for development evaluation
