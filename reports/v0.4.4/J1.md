# Task J1 - Fix stale PONG waiter in NatsWireTransport

## Summary

Fixed a bug in `NatsWireTransport.publishBatch` where stale PONG waiters would remain registered even when publishing to a non-writable socket, causing spurious timeouts and duplicate retries.

## Problem Description

In the `NatsWireTransport` class, the `publishBatch` method was registering the PONG waiter (`this.waitForPong()`) BEFORE checking if the socket was writable. When the socket was not writable (due to connection issues), no PING would be sent but the waiter would remain queued in `this.pongWaiters` until its timeout. The next PONG received on a later connection would then match this stale waiter (FIFO `shift()`), causing every subsequent confirmation to be one PONG late, resulting in spurious timeouts and duplicate retries.

## Solution

Modified the `publishBatch` method in `packages/core/src/services/coordinationFabric.ts`:

1. **Moved writability check before waiter registration**: Check if socket is writable immediately after checking connection state, throwing an error before registering any waiter
2. **Improved error handling for write failures**: When `socket.write()` calls back with an error, remove that waiter and fail all waiters by calling `this.failPongWaiters(err)`
3. **Maintained existing behavior**: All other functionality remains unchanged

## Changes Made

### File: `packages/core/src/services/coordinationFabric.ts`

**Before (lines 470-505):**
```typescript
// Register the waiter before writing so a fast PONG cannot be missed.
const confirmed = this.confirmPublish ? this.waitForPong() : undefined;
confirmed?.catch(() => undefined);

await new Promise<void>((resolve, reject) => {
  if (!socket || socket.destroyed || !socket.writable) {
    reject(new Error('NATS socket is not writable'));
    return;
  }
  socket.write(wirePayload, (err) => {
    if (err) {
      this.connected = false;
      reject(err);
    } else {
      resolve();
    }
  });
});
```

**After:**
```typescript
// Check writability first and throw before registering the waiter
if (!socket || socket.destroyed || !socket.writable) {
  throw new Error('NATS socket is not writable');
}

// Register the waiter immediately before writing so a fast PONG cannot be missed.
const confirmed = this.confirmPublish ? this.waitForPong() : undefined;
confirmed?.catch(() => undefined);

await new Promise<void>((resolve, reject) => {
  socket.write(wirePayload, (err) => {
    if (err) {
      // Remove the waiter on write error and fail all waiters
      this.failPongWaiters(err);
      this.connected = false;
      reject(err);
    } else {
      resolve();
    }
  });
});
```
